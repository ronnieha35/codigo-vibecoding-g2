## Stack

- **Next.js 16** App Router · **React 19** · **TypeScript**
- **Tailwind CSS v4** (via `@tailwindcss/postcss`)
- **shadcn/ui** — component library (New York style, Zinc base). Install components: `npx shadcn@latest add <component>`
- **TanStack Query v5** — server state, caching, mutations. Provider in `app/providers.tsx`
- **TanStack Table v8** — all data tables
- **Axios** — HTTP client. Instance + JWT interceptors in `lib/api/client.ts`
- **Zustand v5** — client state (auth token, user). Store in `lib/stores/auth.store.ts` (persisted to localStorage)

## Architecture

Consumes sibling Django REST API at `../logistica-api`. Base URL from `NEXT_PUBLIC_API_URL` (default `http://localhost:8000/api/v1`).

```
app/
  (auth)/login/        ← public route
  (dashboard)/         ← protected routes (sidebar layout)
    suppliers/ warehouses/ products/ customers/
    transport/ drivers/ routes/ shipments/
  layout.tsx           ← root: wraps with <Providers>
  providers.tsx        ← "use client": QueryClientProvider
lib/
  api/                 ← one file per module (client.ts + {module}.api.ts)
  stores/auth.store.ts ← zustand auth (token, user, logout)
  types/               ← one file per module + api.types.ts
  hooks/               ← TanStack Query hooks per module (created during SDD)
components/
  ui/                  ← shadcn generated
  shared/              ← DataTable, PageHeader, FormModal, DeleteDialog
  {module}/            ← module-specific components (created during SDD)
docs/
  api/                 ← backend API contracts
  specs/               ← generated by /spect agent
  mvp.md               ← module order + status tracker
.claude/commands/      ← SDD agent commands
```

Server Components by default. Add `"use client"` only for event handlers, hooks, browser APIs, or TanStack Query usage.

## SDD Workflow — Orchester

**Rule: build one module at a time. Always check `docs/mvp.md` for the next module.**

Four custom slash commands coordinate the workflow:

| Command | Role |
|---------|------|
| `/orchester` | Identifies next module, coordinates the full cycle |
| `/spect <module>` | Reads `docs/api/<module>.md` → generates `docs/specs/<module>.spec.md`. **Stops for human approval.** |
| `/implement <module>` | Reads approved spec → implements all tasks, marks each `[x]` |
| `/validator <module>` | Verifies implementation against spec → marks ✅ VALIDATED or lists issues |

**Cycle:** `/orchester` → `/spect` → **human approves** → `/implement` → `/validator` → update `docs/mvp.md` → repeat.

shadcn/ui: install components before use during implementation: `npx shadcn@latest add <component>`

## Backend API

Source: `../logistica-api` (Django 6 + DRF · Python 3.14)
Full docs: `docs/api/` directory

**Base URL:** `http://localhost:8000/api/v1/`
**Auth:** JWT Bearer token. Obtain via `POST /api/v1/auth/token/` → `{ access, refresh }`.
Access token lifetime: 60 min. Refresh: 7 days.
**All list endpoints paginated** — 20/page default, max 100. Query: `?page=N&page_size=M`.
**Error shape:** `{ "error": { field: [msg] }, "status_code": N }`

### Modules

| Module | Path | Key Entity |
|--------|------|------------|
| Auth | `/api/v1/auth/` | JWT tokens |
| Suppliers | `/api/v1/suppliers/` | Supplier (name, email, tax_id, city) |
| Warehouses | `/api/v1/warehouses/` | Warehouse (name, city, capacity_m3) |
| Products | `/api/v1/products/` | Product (sku, supplier_id, warehouse_id, stock) |
| Customers | `/api/v1/customers/` | Customer (type: PERSON\|COMPANY, email, tax_id) |
| Transport | `/api/v1/transport/` | Transport (vehicle_type: TRUCK\|VAN\|MOTORCYCLE\|OTHER, license_plate) |
| Drivers | `/api/v1/drivers/` | Driver (user_id OneToOne, transport_id, license_number) |
| Routes | `/api/v1/routes/` | Route + RouteStop[] (ordered warehouse stops) |
| Shipments | `/api/v1/shipments/` | Shipment + ShipmentItem[] + ShipmentStatusHistory[] |

All modules expose standard CRUD: `GET/POST /resource/` and `GET/PUT/PATCH/DELETE /resource/{id}/`.

### Enums

```typescript
type CustomerType    = 'PERSON' | 'COMPANY'
type VehicleType     = 'TRUCK' | 'VAN' | 'MOTORCYCLE' | 'OTHER'
type ShipmentStatus  = 'PENDING' | 'ASSIGNED' | 'IN_TRANSIT' | 'DELIVERED' | 'CANCELLED'
```

### Key behaviors

- **Shipments** are the central entity — link customer + warehouse + driver + transport + route.
  Creating a shipment auto-creates the first `ShipmentStatusHistory`. Changing `status` auto-appends a new history entry. Items array replaces all items on update.
- **Routes** manage `stops[]` (RouteStop) inline — sending `stops` on create/update replaces all stops.
- **Drivers** require a linked Django User (`user_id` OneToOne).
- All entities have `is_active` boolean. All list viewsets filter by `is_active=True`.
- All entities inherit `created_at` / `updated_at` from `BaseModel`.
